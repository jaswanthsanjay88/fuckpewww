# Install Screenshots

This folder contains the installation screenshots used by `install.html`.

## Files

- `step-01-open-extensions.png`
- `step-02-load-unpacked.png`
- `step-03-select-folder.png`
- `step-04-extension-installed.png`
- `step-05-open-menu.png`

## Purpose

The screenshots are ordered to match the install flow:

1. Open the Chrome extensions page.
2. Click Load unpacked.
3. Choose the extracted ZIP folder.
4. Verify the extension is installed.
5. Open the menu path if you need to revisit extensions or troubleshoot.
